# 🧠 How the AI Assistant Works

The chatbot uses a technique called **RAG (Retrieval-Augmented Generation)**.

In simple terms:

> **The system first finds the relevant information from my portfolio, then gives that information to the AI to generate the answer.**

The flow looks like this:

```text
Visitor asks a question
          ↓
Portfolio Website
          ↓
Spring Boot Backend
          ↓
Semantic Search
          ↓
Find relevant portfolio information
          ↓
Send relevant information to Gemini
          ↓
Gemini generates the answer
          ↓
Answer displayed in chatbot
